# Использованный составной промпт

Напиши CLI-инструмент на Python для генерации PDF из HTML-шаблона и CSV-файла.

Требования:

- Скрипт должен читать CSV-файл с колонками `product`, `price`, `qty`, `total`.
- Скрипт должен читать HTML-шаблон с плейсхолдерами вида `{{ product }}`, `{{ price }}`, `{{ qty }}`, `{{ total }}`.
- Для каждой выбранной строки CSV нужно подставлять данные в HTML-шаблон.
- Для каждой строки нужно создавать отдельный итоговый HTML-файл и отдельный PDF-файл.
- PDF и HTML нужно сохранять в папку `output`.
- Для конвертации HTML в PDF используй библиотеку WeasyPrint.
- После генерации готовый PDF должен автоматически открываться в браузере или системной программе просмотра.
- Скрипт должен работать на Windows и macOS.
- В PDF должна корректно отображаться кириллица.
- Длинные строки в таблице должны переноситься и не ломать верстку.
- Таблицы должны иметь аккуратные границы и выравнивание по центру.
- Добавь понятное CLI-меню с нумерацией вариантов.
- Добавь обработку ошибок: отсутствующий CSV, отсутствующий шаблон, пустой CSV, проблемы с кодировкой, отсутствие WeasyPrint и невозможность создать PDF.

Дополнительно:

- Найди HTML-шаблоны и CSV-файлы рекурсивно в выбранных директориях.
- Покажи найденные файлы списком.
- Дай пользователю выбрать шаблон, CSV и строки для генерации.
- Поддержи выбор одной строки, нескольких строк, диапазона и всех строк.
- Не изменяй исходный CSV и HTML-шаблон.
- Очищай имена файлов от запрещенных символов.
